LK Group 앱 아이콘·시작 로고·영어/라오어 통합 수정본
====================================================

이 폴더의 android, ios, assets, lib, supabase 폴더와 pubspec.yaml을
기존 Flutter 프로젝트 루트에 같은 경로로 덮어쓰세요.

이번 수정 내용
--------------
1. Android/iOS 앱 아이콘의 파란 외곽 원을 제거했습니다.
2. 시작 화면에 첨부한 투명 PNG 원본을 적용했습니다.
3. 시작 로고의 오른쪽 Group 글자가 잘리지 않도록 안전 여백을 확보했습니다.
4. 홈의 선적 일정·공지 카드는 영어/라오어에서도 최대 2줄과 말줄임을 유지합니다.
5. 운송 경로명을 한국어·영어·라오어로 표시합니다.
6. 년도·항차의 저장값은 유지하면서 다음처럼 선택 언어로 표시합니다.
   - 한국어: 2026년 / 17항차
   - 영어: 2026 / Voyage 17
   - 라오어: ປີ 2026 / ຖ້ຽວທີ 17
7. 계정 직책(회원, 직원 관리자, 파트너, 총괄 관리자)을 선택 언어로 표시합니다.
8. 계정, 회원가입, 암호 변경, 회원 탈퇴, 견적, 상태, 오류, 일정·공지 관리의
   고정 화면 문구를 영어/라오어로 보완했습니다.
9. 공지·일정의 번역 결과 개수 검증을 보강해 잘못 합쳐진 긴 번역문이
   홈 카드 제목에 들어가지 않도록 했습니다.

주의
----
- DB에 관리자가 직접 입력한 공지 본문, 고객명, 회사명, 메모 등은 원문 데이터입니다.
  화면의 고정 문구만 번역하며 사용자 입력 데이터를 임의로 바꾸지 않습니다.
- 이전 앱 아이콘은 Android/iOS 런처 캐시에 남을 수 있습니다.
  테스트 기기나 에뮬레이터에서 기존 앱을 한 번 삭제한 뒤 새 빌드를 설치하세요.
- 이 ZIP은 기존 overflow_fix 및 final_update ZIP을 모두 대체하는 최신 통합본입니다.
- 별도로 실행할 SQL은 없습니다.

실행 순서
---------
flutter clean
flutter pub get
flutter analyze
flutter run

Release APK 생성
----------------
flutter build apk --release --split-per-abi

테스터에게 전달할 일반적인 Android 파일:
build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
