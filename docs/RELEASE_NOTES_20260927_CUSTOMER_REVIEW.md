# 2026-09-27 고객 ID 통합 검토 및 관리 목록 검색

- 고객 ID 관리에 중복 ID 자동 통합 후보 화면을 추가했습니다. 이름 또는 연락처가 하나 추가된 정확한 조건만 묶고, 그룹 안의 ID를 개별 제외한 뒤 최종 내용을 확인합니다.
- 선택한 고객 중 가장 작은 ID를 유지하고 모든 고유 이름과 연락처를 대표 항목에 합칩니다. 기존 별칭·선적 연결은 보존하며 통합 전 연결 정보를 감사 기록에 저장합니다.
- 별도 배송 고객으로 지정된 이름들은 서버에서도 함께 통합할 수 없습니다. 배송 정보가 있는 후보는 기본 선택하지 않으며 지방배송·수령인·선결제 구분을 확인하도록 안내합니다.
- 시내·지방배송 목록에 정확히 매칭된 고객 ID를 표시하고 고객명, ID, 경로, 업체, 유형, 주소, 결제 구분으로 검색할 수 있습니다.
- 관리 목록에 항목 선택 검색을 추가했습니다. 앱 목록은 기존 실시간 갱신 신호와 화면 복귀 시 갱신하며 입력·처리 중에는 갱신을 미룹니다. 문서 출력과 엑셀 계산 원본에는 검색 조건을 적용하지 않습니다.
- 요청된 데이터 정리: 이전 통합에서 8개 고객 ID와 117개 선적 연결을 복구, 11개 대표 항목의 누락 이름·연락처 보완, 배송 목록에만 있던 4개 지정 고객 ID 발급. 초기 샘플·테스트 견적 6건은 복구 가능한 삭제 대기 상태로 이동했습니다.

검증: 정확한 통합 조건, 제외한 연결 고리로 인한 그룹 분리, 별도 고객 차단, 이전 버전 거절, 권한 검사, 연락처 보존, 앱·웹 확인 후 실행 흐름을 테스트합니다. DB 통합 검증은 트랜잭션 종료 시 롤백합니다.
