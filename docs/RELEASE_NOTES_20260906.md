# 2026-09-06 통합 업데이트

## 앱

- 회원의 송장번호 뒤 4자리 이상 검색과 개인정보 마스킹 결과 지원
- 검색 결과에서 정보 정정 요청, 관리자 승인·반려 지원
- 상담·연락처 8개 항목의 명칭과 링크 통일
- 제공된 `LK GROUP / LK Trading` 로고를 앱 시작 화면에 적용
- Android/iOS 앱 식별자를 `com.lkgrouptrading.app`으로 통일
- Android 업로드 키 설정 예시와 스토어 등록 체크리스트 추가

## 백업 주의사항

이 소스 ZIP은 실행에 필요한 프로젝트와 템플릿을 포함한다. 빌드 결과물,
이전 작업용 중복 템플릿, 로고 중간 작업본은 제외했다. Google Play 업로드 키를
만든 뒤에는 다음 파일을 ZIP과 별도로 암호화하여 보관해야 한다.

- `android/upload-keystore.jks`
- `android/key.properties`

업로드 키를 잃으면 향후 동일 앱 업데이트 배포가 어려워질 수 있다.
