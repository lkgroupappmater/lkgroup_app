# 2026-09-26 지방배송 / 고객 ID 개선

## 요청 범위

- 최대 3장 동시 업로드·송장 인식, 같은 수령인 후보 조회 재사용, 인덱스 기반 후보 검색.
- 명세서 또는 화물이 선택된 경우 서버에서 수령인 정보를 확정하고 사진은 송장번호·업체만 인식.
- 전체 송장 확인·선택 체크박스. 번호·업체·연결 대상이 불완전한 항목은 미확인 상태 유지. 확인된 전체 등록 규칙 유지.
- 화물 참고 사진 모드: 송장번호·업체·OCR 없이 선택된 명세서/화물/별도 참조에 바로 사진 첨부. 재시도 시 같은 배치로 중복 방지.
- 고객 ID 전체/중복·유사/불일치 필터, 관련 고객 및 연결 자료 수 표시.
- 이름·전화번호 오타 후보 비교, 남길 ID 선택·비교 확인 후 통합. 확인된 과거 표기를 보관해 이후 같은 표기가 다시 들어오면 같은 고객 ID로 연결.
- 변경 사유 입력은 선택. 변경 이력 자동 기록, 기존 001/002 ID 보호, 오래된 화면의 덮어쓰기 방지.
- 불일치 자료에서 올바른 ID를 선택해 연결 수정. 실제 고객 통합이나 데이터 교정은 관리자가 확인 후 실행.
