# 승인된 Excel 글꼴 복구 · DB 편집 반영


- 고객 리스트 제목과 지방/시내배송 고객 셀의 글꼴·크기·색은 사용자가 다시 첨부한 해상 BASE를 따른다. 물품 입고 내역은 정상 원본의 제목 16pt·상단 항목 9pt로 복구한다. 기존 셀의 테두리·정렬·표 크기·숫자 형식·수식·VBA를 교체하지 않고 글꼴 속성만 복구한다.
- 복구는 수정 기준 시각 전에 등록된 BASE/항차/공통 배송 원본에만 적용한다. 이후 새로 업로드하는 파일의 서식은 그 파일이 기준이며, 새 기본값으로 덮어쓰지 않는다. 공통 배송 원본을 항공에 복사하기 전에 같은 복구를 적용한다.
- 배송 고객 영역 B:H의 실제 글꼴 연결도 출력 직전에 검사한다. DB 값이 바뀌어도 원본 글꼴·크기·색과 기존 배송업체 대안·순서·병합을 유지한다. 오류 시 파일 게시를 중단한다.
- 할인 연락처/고객명을 앱·웹에서 수정하면 저장된 할인 차트 행을 갱신한다. 기존 번호를 찾지 못해 할인을 0으로 만들고 그룹 끝에 추가하던 문제를 막으며, 수정 행이 모호하면 임의로 선택하지 않는다. 할인율·회원별 번호 매칭·배송 매칭 및 DB 스키마는 그대로 유지한다.
- 통합문서 v16 / 저장 원본 보정 경로 v6로 이전 다운로드 캐시를 갱신한다. 등록된 각 전화번호 단독 입력과 차트 편집 이후 실제 명세서 할인율/할인액까지 기본 계산 엔진에서 검증한다. Windows Excel의 사용자 확인과 자동 검증은 구분한다.
