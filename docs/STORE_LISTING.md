# LK Group Trading 스토어 등록 문구

## 짧은 설명

한국–라오스 화물 조회, 운송 일정, 공지와 상담을 하나의 앱에서 확인하세요.

## 자세한 설명

LK Group Trading은 한국과 라오스를 잇는 해상·항공·현지 배송 화물을 관리하는 고객·파트너용 앱입니다.

- 화물번호·송장번호 조회
- 수취인 정보 오류 시 송장 뒷자리 확인 요청
- 선적 일정·공지사항
- 기준환율 및 운임 확인
- 한국어·영어·라오어 지원
- 카카오톡·WhatsApp·Facebook·블로그·사무실 위치 연결
- 회원, 협력사, 직원, 관리자별 맞춤 기능

화물·운임·통관·일정 확정사항은 LK Group Trading 직원에게 최종 확인해 주세요.
