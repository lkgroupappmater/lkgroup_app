Patch191 - 고객 리스트 출력
- 기존 고객 리스트 관리/영수증번호+Zone 수정 유지
- 하단 이미지 저장(PNG) 버튼
- 하단 PDF 저장 / 프린트용 버튼
- 출력 양식: Excel 고객 리스트와 유사한 표
  영수증 번호 / 고객명·회사명 / 연락처 / Zone / 수량 / 비고
- PNG: 전체 고객을 한 장의 긴 이미지로 저장
- PDF: 36명 단위 A4 가로 페이지, 마지막 데이터까지만 출력
- PDF는 한글 폰트 파싱 문제를 피하기 위해 앱이 렌더링한 표 이미지를 PDF에 삽입

박성호 할인 로직은 이번 패치에서 건드리지 않음.
