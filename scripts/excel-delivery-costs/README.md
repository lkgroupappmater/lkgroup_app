# 한국–라오스 해상·항공 선결제 배송비 수식

지방배송·시내배송은 **기본 할인 미적용**입니다. 선결제 명세서의 마지막 화물 다음에 비용 이름을 표시하고 금액은 직원이 직접 입력합니다. 비용 이름을 수정해도 됩니다. `할인 적용`을 `적용`으로 바꾼 경우에만 운임 할인율을 배송비에도 적용합니다.

## 현재 반영 범위

- 앱·웹: 같은 명세서 기타 비용 데이터를 사용합니다. 미입력 배송비는 이름만 표시하며 실제 금액으로 저장하지 않습니다.
- 이 폴더: 기존 XLSM 원본에 적용할 수식과 Windows Excel 적용 스크립트입니다. GitHub Pull만으로 PC에 보관된 엑셀 원본이 자동 수정되지는 않습니다.
- 서버의 엑셀 다운로드 템플릿에는 이 스크립트를 자동 실행하지 않습니다. 아래 적용본을 사용하는 방식입니다. 앱·웹 비용과 엑셀에 수동 입력한 비용을 서로 자동 동기화하는 기능은 아닙니다.

## 지원 원본

2026년 9월에 제공된 `1. Kor-Lao Sea ... 완전자동화(2).xlsm`와 `2. Kor-Lao Air ... 완전자동화.xlsm`을 기준으로 작성했습니다. `물품 입고 내역`이 5번째 시트이고 `LKS 01` 또는 `LKA 01`, `고객 리스트`, 명세서의 `R6` 행 기준 셀이 있는 원본입니다. 해상은 입력 행 6:1005, 항공은 6:205 범위를 유지합니다.

## Windows Excel에서 적용

Excel에서 대상 파일을 닫은 다음, 저장소 폴더의 PowerShell에서 실행합니다. 해상·항공 파일마다 한 번씩 실행하세요.

```powershell
git pull origin master
.\scripts\excel-delivery-costs\apply.ps1 -WorkbookPath 'C:\실제경로\해상원본.xlsm'
.\scripts\excel-delivery-costs\apply.ps1 -WorkbookPath 'C:\실제경로\항공원본.xlsm'
```

원본 옆에 `_배송비추가.xlsm`이 생성됩니다. 같은 이름이 있으면 덮어쓰지 않고 중단합니다. 다른 출력 이름은 `-OutputPath 'C:\실제경로\다른이름.xlsm'`로 지정합니다. 원본과 출력 경로를 동일하게 지정할 수 없습니다.

기존 행 맞춤 매크로가 화물 10개일 때 배송비 행을 누락하므로 해당 조건도 함께 수정합니다. Excel이 VBA 프로젝트 접근을 차단하면 스크립트는 원본을 저장하지 않고 중단합니다. 이 경우 **Excel → 파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 매크로 설정 → VBA 프로젝트 개체 모델에 대한 신뢰할 수 있는 액세스** 설정이 필요합니다. 스크립트가 이 보안 설정을 변경하지는 않습니다.

## 입력 방법

새 `배송비 입력` 시트에서 해당 영수번호 행을 찾습니다.

| 열 | 내용 | 입력 방식 |
|---|---|---|
| A | 영수번호 | 기존 고객 리스트·화물에서 채움 |
| B | 배송 구분 | 원본의 배송 구분 수식 참조 |
| C | 비용 이름 | 선결제이면 지방배송/시내배송 자동 표시, 수정 가능 |
| D | 금액 USD | 수동 입력, 빈칸은 미입력·0은 무료 |
| E | 할인 적용 | 기본 **미적용**, 필요한 경우만 적용 선택 |
| F | 고객명 | 원본 참조 |
| G | 입력 상태 | 미입력·입력 완료·금액 확인 |

한 영수번호의 배송비 1개를 관리합니다. 여러 업체 비용을 따로 입력할 때는 앱·웹의 기타 비용 기능을 사용하세요. 입력 시트는 최대 201개 영수번호를 지원하며 기존 입력값은 재실행 시 유지합니다.

화물 수가 바뀌면 기존 명세서 행 맞춤 버튼을 다시 실행하세요. 빠르게 확인 시트는 설치 시점의 가장 많은 화물 수에 맞춰 여유 행을 확보합니다. 이후 더 큰 명세서가 생기면 스크립트를 해당 적용본에 다시 실행해 새 출력본을 만드세요.

## 수식 기준

전체 수식은 `formulas.json`에 있으며, 해상·항공의 차이는 `sourceEnd` 값입니다. `W6:W11`은 인쇄 영역 밖의 보조 셀입니다. 병합 셀인 N2:N3와 L4:N4는 건드리지 않습니다.

- W6: 비용 이름, W7: 수동 금액, W8: 할인 적용 여부.
- W9: 영수번호 매칭 행, W10: 해당 명세서의 실제 화물 수.
- W11: 할인에서 제외할 배송비.
- B열: `행 순번 = 실제 화물 수 + 1`이면 배송비 이름을 표시.
- N열: 같은 행에 수동 금액을 표시. 미입력 금액은 빈칸.
- 자동 할인: `(전체 USD 합계 − 할인 제외 배송비) × 할인율`.
- 별도 고정 할인액: 원본 M열 입력을 유지하고 할인 가능한 잔액 범위에서만 적용.
- 세금·환율·원본 QR·도장·기존 시트 순서와 매크로 형식은 보존합니다.

## 검증과 한계

`formula-validation.json`은 Artifact Tool에서 실제 수식을 계산한 24개 시나리오 결과입니다. 해상·항공 각각 지방/시내배송, 기본 미적용/선택 적용, 운임 100% 할인, 과도한 고정 할인액, 빈칸/0원, 일반 배송, 화물 0·9·10·11개 뒤의 배송비 위치를 확인했습니다.

이 Linux 작업 환경에는 Microsoft Excel이 없어 **PowerShell COM 실행, VBA 실행 및 실제 XLSM 인쇄는 아직 검증하지 못했습니다.** 수식 검증용 복사본으로 원본을 교체하지 않았습니다. Windows 적용 후 대표 명세서 1건에서 금액과 인쇄 영역을 확인하세요. 예: 운임 USD 100, 할인 20%, 배송비 USD 20 → 기본 합계 USD 100, 할인 적용 선택 시 USD 96(세금 전).
